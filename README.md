# 圆桌会议系统

> **认知演化圆桌 × 32专家深度辩论 × 直达本质洞见**

## 核心功能

- 🎯 **圆桌洞见生成** - 6位专家深度辩论，直达本质、直面本心、直击痛点
- 🧠 **专家库训练** - 32位专家档案，1,480+次训练，持续进化
- 📊 **深度训练引擎** - WebSearch + 知乎MCP + LLM辩论驱动升级
- 💡 **通俗表达训练** - 用最通俗的语言解释最深刻的哲思
- 🎨 **圆桌 OS HTML-PPT渲染** - 一条主链路生成阅读型单文件 HTML-PPT

## 圆桌洞见案例

### 职场困境：INTJ倦怠决策

**话题**：天崩公司环境，改变自己、适应还是逃离？

**专家**：达利欧、芒格、卡尼曼、弗洛姆、塔勒布、项飙

**核心洞见**：
> 逃离不是逃避，是理性选择。INTJ在烂公司的痛苦是系统匹配问题——你的系统思维被压制、认知资源被消耗、核心竞争力被摧毁。留下的损失是确定的，逃离的收益是可能的。

**最强金句**：
- "你的系统2被持续压制，就像让马拉松选手去跑百米冲刺" — 卡尼曼
- "你就像建筑师被扔进工地，不给你图纸不给你材料" — 项飙
- "你想知道该不该离开，先想：如果你留下，你会怎么死？" — 芒格

### AI时代工作替代

**话题**：AI替代工作后，人类还有工作吗？

**专家**：老子、尼采

**核心洞见**：
> 不是'顺应vs驾驭'的对立，而是'在顺应中超越'。像大禹治水，深刻理解AI的本性，通过疏导而非对抗来引导AI。
