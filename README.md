## 系统架构

```
输入（书籍内容/话题）→ 专家选择（6人）→ 7轮深度讨论 → HTML PPT 输出
                                      ↑
                                 专家库(47+)
```

### 核心流程

1. **输入**：用户提供书籍内容或讨论话题
2. **专家选择**：从 47+ 专家库中选择立场差异最大的 6 位
3. **深度讨论**：7 轮交锋，每轮包含标题页 + 发言页(2-3人/页) + 碰撞页
4. **洞见提炼**：每轮产出洞见句（因果推理格式），全场 5 个核心洞见
5. **HTML 生成**：自包含 CSS，完整导航，弹性多页布局

---

## V2.4 核心特性

### 弹性多页布局
- 每轮 3-5 页：标题页(留白) + 发言页(2-3人/页) + 碰撞页(独立)
- 一个话题可以跨多页，不强制压缩
- 总页数 35-45 页（弹性）

### 情节锚定机制
- 每次发言必须引用书中具体情节（人物+事件+对话）
- 禁止脱离文本的纯抽象讨论
- 从情节出发推导观点，不是先有观点再找例子

### 独立碰撞页
- 每轮 2-3 轮来回反驳
- 5 种碰撞类型：情节反驳、细节挑战、逻辑追问、框架质疑、反例引入
- 颜色标记区分碰撞类型

### 完整导航系统
- 键盘：↑↓←→ / 空格 / PageUp/Down / Home / End / T(目录) / Escape
- 鼠标：滚轮翻页 / 点击翻页 / 导航圆点
- 触摸：上下滑动 / 左右滑动
- 目录 TOC：侧边栏呼出，点击跳转

### CSS 自包含
- 零外部依赖（不引用 Google Fonts、CDN、base.css）
- 系统字体栈：Noto Sans SC / PingFang SC / Microsoft YaHei
- 响应式三档：桌面(>1024px) / 平板(768-1024px) / 手机(<768px)
