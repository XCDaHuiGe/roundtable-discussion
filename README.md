# 圆桌会议 V2.0 — Deep Discussion Roundtable

> **让专家在圆桌上深度交锋，观点在碰撞中演化，洞见在对话中产出。**

---

## 项目定位

圆桌会议 V2.0 是一个**深度讨论导向**的圆桌系统，核心范式从"蒸馏知识框架"转变为"深度对话产出洞见"。

| 维度 | V1.0 | V2.0 |
|:---|:---|:---|
| **核心导向** | 蒸馏知识框架 | 深度解读讨论 |
| **讨论轮次** | 3轮 | 5-8轮（动态） |
| **专家互动** | 顺序发言 | 实时反驳+追问 |
| **产出质量** | 知识结构化 | 认知推进型 |
| **HTML PPT** | 知识展示型 | 洞见呈现型 |

## 核心特性

### 1. 深度讨论引擎
- 单话题 5-8 轮深度交锋
- 强制碰撞机制：直接反驳、条性质疑、反例挑战
- 每轮必须有认知增量（Insight Delta）
- 支持"分支讨论"：当发现新维度时分裂讨论

### 2. 认知演化追踪
- 假设演化图谱：追踪每个假设的修正轨迹
- 认知断裂点识别：标记思维范式转变时刻
- 洞见密度指标：每轮讨论的洞见产出率

### 3. 专家互动机制
- 角色分配：主辩手、挑战者、调和者、观察者
- 强制碰撞：每轮至少2次有效碰撞
- 禁止附和：禁止"我同意X的观点"式的表面附和

### 4. 洞见提炼
- 核心洞见：3-5个（必须是讨论中新产生的）
- 颠覆性观点：至少1个
- 可操作建议：至少2个
- 开放问题：2-3个（留给读者思考）

## HTML PPT 三层架构

| 层级 | 占比 | 内容 |
|:---|:---:|:---|
| **洞见全景** | 30-40% | 核心洞见、颠覆性观点、关键分歧图谱 |
| **深度讨论过程** | 40-50% | 轮次演进、观点碰撞、Shock Event、演化时间线 |
| **认知演化与开放问题** | 20-30% | 假设演化、认知断裂点、开放问题 |
