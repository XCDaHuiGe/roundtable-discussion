# 圆桌会议 V5.0 — 互联网自进化认知引擎

> **核心原则：系统从互联网学习，专家在讨论中进化**
> **给一个话题，系统自动从知乎+全网挖掘真实素材，6位跨领域专家展开3轮深度交锋。**

---

## 系统架构（V5.0）

```
用户输入话题
    ↓
【Phase 0】互联网内容挖掘
知乎MCP + WebSearch → 真实素材包
    ↓
【Phase 1】生成圆桌洞见（基于互联网真实素材）
加载专家库 → 矛盾提取 → 3轮交锋
    ↓
【Phase 2】渲染HTML
JSON → V8渲染器 → 独立幻灯片HTML
    ↓
【Phase 3】持续训练（互联网知识注入）
讨论 → 发现专家薄弱项 → 互联网搜索补充 → 反哺专家档案
    ↓
下一轮：更强的专家 + 更深的互联网挖掘 = 更高质量的讨论
```

**与V4.0的根本区别**：用户不需要提供任何内容，系统从互联网学习，专家在讨论中持续进化。

## 工作流程

### V5.0 全自动流水线

```
用户输入话题
    ↓
Step 0: 互联网内容挖掘
├─ 知乎MCP搜索 → 真实书评/观点/争议
├─ WebSearch补充 → 核心观点/批评/案例
└─ 整合 → content/{话题}_素材.md
    ↓
Step 1: 生成讨论JSON（基于互联网素材）
├─ 加载专家档案
├─ 提取矛盾点（来自真实争议）
└─ 3轮讨论（立场→攻击→整合）
    ↓
Step 2: 渲染HTML
├─ V8格式转换
└─ render_v8.py → output/{话题}_圆桌洞见.html
    ↓
Step 3: 持续训练（互联网知识注入）
├─ 提取专家实战表现
├─ 诊断薄弱项 → 针对性互联网搜索
└─ 反哺升级专家档案
```

### 渲染命令

```powershell
# 转换JSON格式
python engine/convert_to_v8.py content/{话题}_讨论.json content/{话题}_v8.json

# 渲染HTML
python engine/render_v8.py content/{话题}_v8.json output/{话题}_圆桌洞见.html

# 验证HTML
python tools/validate_html.py output/{话题}_圆桌洞见.html
```

## 专家能力进化机制

### 提升体现（3个维度）

| 维度 | 体现 | 证据 |
|:---|:---|:---|
| **档案厚度** | 参与话题越多，档案越厚 | 档案从初始语录 → 讨论提取 → 互联网补充 |
| **观点精准度** | 新讨论引用更多真实案例 | 来自知乎MCP+WebSearch的互联网真实数据 |
| **防御韧性** | 被攻击后能更有效反驳 | 跨话题训练后知识图谱更完整 |

### 进化闭环流程

```
Phase 3: 持续训练
    ↓
[诊断] 提取专家实战表现
    ↓
[诊断] 发现专家薄弱项（话题盲区/理论缺失/案例不足）
    ↓
[注入] 互联网针对性搜索（知乎MCP → 搜索专家在该领域的最新观点）
    ↓
[升级] 将新语录/理论/案例追加到专家档案
    ↓
[验证] 下轮讨论使用升级后的档案
    ↓
循环 → 专家越用越强
```

### 具体证据示例

**以罗翔为例**：
- 初始档案：`法治思想`、`程序正义`、`刑罚 deterrent effect`
- 第1轮讨论后：新增「文化主权」「权力集中批判」等现代法治争议
- 第6轮讨论后：档案从初始语录扩展到「技术伦理」「AI立法困境」等前沿话题
- 进化结果：在「虚构世界资产化」话题中，罗翔能提出更精准的法律边界分析

**以李诞为例**：
- 初始档案：`幽默本质是悲剧`、`解构神圣`、`躺平哲学`
- 讨论后：新增「喜剧边界」「冒犯的艺术」「娱乐至死vs娱乐至智」
- 进化结果：在「影视模因」话题中，李诞能精准拆解散户情绪的喜剧结构

### 互联网知识注入证据

每次讨论后，训练引擎会自动：
1. 扫描讨论中专家暴露的知识盲区
2. 用知乎MCP搜索该专家在该话题的最新观点
3. 将新语录追加到档案的「训练记录」章节

**查看方法**：打开 `expert-library/experts/{领域}/{专家}.md`，滚动到底部可见「实战训练记录」章节。
