# Data Master 产品说明文档

版本：v1.0  
对应原型：`output/data-master-ui-image2.html`  
更新时间：2026-06-10

## 1. 产品定位

Data Master 是一个元数据驱动的通用 ETL 管理平台，用于统一管理日常业务数据上传、字段映射、数据质量检查、历史文件替换、月度定版、组织架构和系统参数。

平台核心目标：

- 用“逻辑表 + 元数据”驱动上传识别、字段映射和入库。
- 用“业务日期”组织日历、补传、替换和定版。
- 用统一上传流程支持普通上传、日历缺失补传、历史文件替换。
- 用组织架构二维表统一维护区域、城市、站点关系。

## 2. 用户角色

| 角色 | 主要能力 |
|---|---|
| 管理员 admin | 全部菜单、用户管理、系统设置、强制解锁、删除用户、组织架构上传 |
| 数据维护员 editor | 数据上传、待办处理、历史文件下载/替换、元数据维护 |
| 查看用户 viewer | 查看日历、历史文件、元数据、月度状态 |
| 城市/区域用户 scoped_user | 仅查看授权组织范围内的数据和上传状态 |

## 4. 核心业务流程

### 4.1 登录

用户输入账号密码登录。忘记密码时，登录页展示系统设置中维护的管理员联系方式。

登录页布局：

- 左侧 60%：品牌区。
- 右侧 40%：登录表单。
- 忘记密码提示：联系管理员重置。

### 4.2 数据日历

日历按业务日期展示当日数据完成情况。

状态规则：

| 状态 | 含义 |
|---|---|
| 全量 | 当日必传表均已完成 |
| 部分 | 当日存在未完成或异常表 |
| 暂无数据 | 当日没有上传记录 |
| 未来日期 | 不允许进入详情 |

交互规则：

- 点击有效日期进入日历详情页。
- 点击未来日期只提示，不进入详情。
- 月份切换时需要展示加载状态。

### 4.3 日历详情

展示某一业务日期下所有逻辑表的上传状态。

操作规则：

- 缺失或失败表点击“上传”，进入数据上传页。
- 进入上传页时自动预填业务日期和逻辑表。
- 预填模式跳过表名识别，上传后直接进入字段映射、DQ 和入库流程。
- “替换”操作先弹确认框，再进入上传页。
- 替换只影响单个文件。

### 4.4 数据上传

上传页支持三种入口：

| 入口 | 行为 |
|---|---|
| 普通上传 | 用户选择文件，系统识别表名 |
| 日历详情补传 | 自动预填表名和业务日期，跳过表名识别 |
| 历史文件替换 | 自动预填表名、业务日期、`replace_file_id` |

上传页能力：

- 支持 `.xlsx`、`.xls`、`.csv`。
- 展示文件列表、匹配表、校验状态。
- 支持取消批次，取消前必须确认。
- 支持刷新后恢复当前批次状态。
- 网络断连时展示恢复提示，恢复后继续轮询。

### 4.5 上传处理结果

上传完成后进入上传处理结果页。

处理链路：

1. 选择文件
2. 创建批次
3. 表名识别、字段映射、DQ 检查
4. 待办处理
5. 提交入库

提交规则：

- 存在阻塞待办时，不允许提交入库。
- 待办处理完成后，允许提交。
- 可入库文件进入入库流程。
- 异常处理动作写入日志。

待办处理方式：

| 处理方式 | 后续动作 |
---|---|
| 映射到已有字段 | 更新本批次字段映射，不改元数据结构 |
| 新建字段 | 更新元数据字段列表后继续 DQ |
| 忽略该列 | 该列不入库、不更新元数据，其余字段继续 DQ 和入库，并记录日志 |

### 4.6 历史下载与替换

历史下载页用于查看历史上传文件。

操作规则：

- 下载：下载当前版本文件。
- 替换：只替换单个文件。
- 删除：需要确认，且记录审计日志。

替换流程：

1. 用户点击历史文件“替换”。
2. 系统弹出确认框。
3. 确认后跳转上传页。
4. 上传页预填表名、业务日期、`replace_file_id`。
5. 新文件提交成功后，旧文件状态标记为“已替换”。

### 4.7 元数据管理

元数据由逻辑表和字段组成。

逻辑表管理：

- 逻辑表名
- 显示名
- 写入策略
- 主键
- 字段数
- 状态

元数据详情：

- 表基本信息可直接编辑。
- 字段表只读展示。
- 字段新增/编辑通过弹窗完成。
- 字段删除需要确认。

编辑锁：

- 用户进入元数据详情时获取编辑锁。
- 锁超时自动释放。
- 管理员可以强制解锁。
- 后端失败时前端需要回滚锁状态。

### 4.8 月度定版

月度定版页展示某月数据完成情况。

当前规则：

- 页面不提供“发起定版”按钮。
- 展示月份状态，例如“2026年6月 · 未定版”。
- 管理员可执行解锁。

同月重复上传规则：

| 动作 | 含义 |
|---|---|
| 覆盖 | 旧批次标记为 `superseded`，新批次成为有效版本 |
| 追加 | 新文件合并到现有批次，保留版本链路 |

### 4.9 组织架构

组织架构通过上传二维 Excel 维护，不再分区域、城市、站点三级分别管理。

页面结构：

- 顶部只保留一个按钮：上传组织架构 Excel。
- 下方直接展示组织架构表格。

Excel 和表格字段：

| 字段 | 说明 |
|---|---|
| 区域名称 | 站点所属区域 |
| 城市名称 | 站点所属城市 |
| 站点名称 | 站点显示名称 |
| 站点ID | 站点唯一标识 |
| 混送（主站） | 是否为混送站点，或是否关联主站 |
| 主站ID | 混送场景下关联的主站 ID，无则为空 |

规则：

- 每行代表一个站点。
- 后端按 `站点ID` 判断唯一性。
- `混送（主站）=是` 时，`主站ID` 必填。
- 主站 ID 必须存在于同一组织表或当前有效组织版本中。

### 4.10 用户管理

用户管理支持：

- 新建用户。
- 编辑用户。
- 重置密码。
- 启用/禁用。
- 删除用户。

删除规则：

- 删除前必须二次确认。
- 当前登录用户不可删除。
- 删除失败时展示错误原因。
- 删除动作写入审计日志。

### 4.11 系统设置

系统设置包含：

- 单文件最大上传大小。
- 批次超时时间。
- DQ 空值阈值。
- 文件版本保留数。
- 登录页管理员联系人、电话、邮箱。
- 磁盘空间监控。

磁盘策略：

- 超过 85% 提醒管理员。
- 超过 95% 限制新增上传任务。

## 5. 关键状态字典

### 5.1 文件状态

| 状态 | 说明 |
|---|---|
| pending | 等待处理 |
| recognizing | 表名识别中 |
| mapped | 字段映射成功 |
| dq_passed | DQ 通过 |
| dq_warning | DQ 提醒 |
| blocked | 阻塞待办 |
| imported | 已入库 |
| replaced | 已替换 |
| deleted | 已删除 |

### 5.2 批次状态

| 状态 | 说明 |
|---|---|
| draft | 草稿批次 |
| processing | 处理中 |
| todo_required | 需要处理待办 |
| ready_to_submit | 可提交 |
| importing | 入库中 |
| completed | 完成 |
| cancelled | 已取消 |
| failed | 失败 |
| superseded | 已被覆盖 |

## 6. 验收要点

- 所有页面可以从侧边栏进入。
- 日历有效日期可以进入详情，未来日期不可进入。
- 日历详情缺失表上传会进入上传页预填模式。
- 历史文件替换必须先确认，且只替换单个文件。
- 上传处理结果存在阻塞待办时不能提交。
- 待办“忽略该列”不入库、不更新元数据。
- 元数据字段不能在表格内直接编辑，必须弹窗编辑。
- 组织架构页只有一个上传按钮，下方表格字段固定为 6 列。
- 用户删除必须确认。
- 页面不得出现内部滚动条。
