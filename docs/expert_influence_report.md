# 专家影响力报告（可验证版 V2.1）

## 成功标准（最小设计）

```
影响力分数 = 金句×3 + 影响他人×2 - 被影响×1

验证方式：
- 金句：被记录在key_quotes的金句数
- 影响他人：观点被stance_evolution.change_reason引用的次数
- 被影响：自己的立场被他人观点改变的次数
```
