# 圆桌会议持续训练引擎 V3.0

> **V2.0 → V3.0 核心升级：从"追加式"到"进化式"**
> **不是积累内容，是提炼策略。不是量变，是质变。**

---

## 一、V3.0 核心升级

### V2.0 问题（追加式）

```
模拟发言: [v1条目, v2条目, v3条目, ...]  ← 无限膨胀
专家.md 越来越大 → 变成"万金油" → 失去锋芒
```

### V3.0 解决（进化式）

```
核心信念: 不变（专家的"灵魂"）
分析框架: 升级（从简单判断 → 多维度分析）
精选发言: 保留最好的3-5条，淘汰弱的
攻击策略: 从"会反驳" → "知道从哪反驳最痛"
```

**关键洞察：专家.md 应该保持恒定大小，但密度越来越高。像合金一样，体积不变，硬度增加。**

---

## 二、专家强度三层次

| 层次 | 低效提升（V2.0） | 高效提升（V3.0） |
|:---|:---|:---|
| **论点精度** | 追加10条泛泛发言 | 提炼出3条"一击致命"的攻击角度 |
| **反驳深度** | 记录"反驳了" | 记录"从哪个角度、用什么证据、戳中了什么要害" |
| **认知框架** | 积累更多案例 | 形成专属分析模型（如：芒格的多元思维模型） |

**真正让专家变强的不是"他上次说了什么"，而是：**
1. 他发现了自己的弱点（比如"我总在现实案例上输"）
2. 他学到了对手的招式（比如"鲁迅总从人性角度切入，我也可以"）
3. 他形成了自己的方法论（比如"每轮必须有一个数字+一个反例"）

**所以：提取的不应该是"内容"，应该是"策略"。**

## 三、三种训练来源

| 来源 | 速度 | 质量 | 说明 |
|:---|:---|:---|:---|
| 人给话题 | 慢 | 高 | 有真实阅读背景，讨论有根基 |
| 自生成话题 | 快 | 中 | 用专家自己关心的议题生成讨论 |
| **对抗训练** | **最快** | **高** | **让专家互相出题、互相挑战** |

### 对抗自训练方案（无需人参与）

```
训练循环：

1. 从每位专家的"核心信念"中提取矛盾点
   → 孔子相信"人性本善" vs 荀子相信"人性本恶"
   → 自动产生讨论话题："人性本质是什么？"

2. 两位专家就这个话题进行深度碰撞

3. 提取表现数据，升级专家

4. 从升级后的专家中提取新的矛盾点
   → 产生新话题

5. 重复
```

**本质：专家之间的信念差异就是天然的训练话题。不需要外部输入。**

## 四、训练参数

### 启动指令

```
"对专家库进行对抗训练"
"训练5轮，每轮心跳输出"
"deep模式训练，目标90分"
```

### 参数配置

| 参数 | 说明 | 默认值 |
|:---|:---|:---|
| 轮数 | 训练多少轮 | 5轮 |
| 模式 | quick/normal/deep | normal |
| 目标评分 | 达到该评分即停止 | 85 |
| 心跳间隔 | 每隔多少秒输出一次状态 | 30秒 |
| 训练来源 | 对抗/话题/混合 | 对抗 |

## 五、训练流程（每轮循环）

### 完整流程

```
┌─────────────────────────────────────────────────────────────┐
│  Round N 开始                                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step 1: 生成话题（对抗训练）                                │
│  ├─ 提取专家信念差异                                        │
│  ├─ 自动生成讨论话题                                        │
│  └─ 心跳输出："[Round N] 话题生成完成：{话题}"              │
│                                                             │
│  Step 2: 生成讨论                                           │
│  ├─ 加载专家档案                                            │
│  ├─ 生成3轮讨论（立场→攻击→整合）                          │
│  └─ 心跳输出："[Round N] 讨论生成完成，共{X}页"            │
│                                                             │
│  Step 3: 提取策略（不是内容！）                              │
│  ├─ 分析每位专家的弱点                                      │
│  ├─ 提取对手的招式                                          │
│  ├─ 识别有效的方法论                                        │
│  └─ 心跳输出："[Round N] 策略提取完成"                      │
│                                                             │
│  Step 4: 进化式升级专家                                     │
│  ├─ 更新攻击策略（不是追加发言）                            │
│  ├─ 精选发言（保留最好的3-5条，淘汰弱的）                   │
│  ├─ 升级分析框架                                            │
│  ├─ 保持.md大小恒定（密度增加）                             │
│  └─ 心跳输出："[Round N] 专家升级完成"                      │
│                                                             │
│  Step 5: 质量评分                                           │
│  ├─ 8维度评分                                               │
│  ├─ 对比上轮评分                                            │
│  └─ 心跳输出："[Round N] 评分：{分数}（+{增量}）"          │
│                                                             │
│  Step 6: 记录进化日志                                       │
│  └─ 心跳输出："[Round N] 完成，耗时{X}秒"                  │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  Round N 结束                                               │
│  输出本轮总结：                                              │
│  ├─ 本轮话题                                                │
│  ├─ 本轮评分                                                │
│  ├─ 本轮升级内容                                            │
│  └─ 距离目标还差多少                                        │
└─────────────────────────────────────────────────────────────┘
```

## 八、进化式升级操作规范

### 专家.md 结构（恒定大小）

```markdown
# {专家名}

## 核心信念（不变）
- 信念1
- 信念2

## 分析框架（升级）
- V1: 简单判断
- V2: 多维度分析
- V3: 专属分析模型

## 精选发言（恒定3-5条）
1. 最精准的一击
2. 最有深度的反驳
3. 最具风格的表达

## 攻击策略（升级）
- V1: 会反驳
- V2: 知道从哪反驳
- V3: 知道从哪反驳最痛

## 方法论（形成）
- 每轮必须有一个数字
- 每轮必须有一个反例
- 每轮必须引用对手的弱点
```

### 升级操作

```
不是：追加10条新发言
而是：
1. 淘汰最弱的2条发言
2. 新增1条更精准的发言
3. 更新攻击策略（从"会反驳"→"知道从哪反驳最痛"）
4. 升级分析框架（新增一个维度）
5. 形成方法论（提炼通用规则）
```

## 九、评分体系（V3.0 升级）

### 8维度评分

| 维度 | 权重 | 评分标准 |
|:---|:---|:---|
| 论点精度 | 20% | 每个论点是否"一击致命" |
| 反驳深度 | 20% | 是否"从哪个角度、用什么证据、戳中什么要害" |
| 认知框架 | 15% | 是否形成专属分析模型 |
| 现实感 | 15% | 每轮有1+真实世界反例 |
| 认知反转 | 10% | 观点被打碎后重建 ≥ 1次 |
| 人味 | 10% | 口语化表达，无学术腔 |
| 结构完整 | 5% | JSON Schema 验证通过 |
| 渲染质量 | 5% | HTML 验证通过 |

### 评分规则

- 每轮结束后自动评分
- 评分记录到进化日志
- 评分提升的**根本原因**是专家策略升级了
- 同一个话题，专家V2的评分应该 > 专家V1的评分
