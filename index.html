Core System

圆桌洞见核心能力

从话题到洞见，全自动认知榨取引擎 + 深度训练系统。

话题 → 互联网素材
用户给一个话题，系统自动从知乎+全网挖掘真实讨论素材，不再依赖用户提供内容。
3轮深度交锋
立场表达 → 互相攻击 → 认知整合。每轮必须有专家间的直接反驳，禁止各说各话。
32位专家库
5大领域：哲学、经济、心理、科技、文学。每位专家可持续学习升级。
深度训练引擎
WebSearch + 知乎MCP + LLM辩论驱动专家升级，融合增强式学习，策略持续进化。
多格式输出
每份洞见为独立HTML幻灯片，支持键盘/触摸导航，零外部依赖。
来源可追溯
所有观点必须标注互联网来源，每个矛盾点来自真实争议，每个案例引用真实数据。
