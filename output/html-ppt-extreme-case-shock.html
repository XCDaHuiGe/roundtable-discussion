DISPLAY LOGIC / EVIDENCE WALL

把材料贴到墙上，而不是排进卡片

当内容里有事件链、人物关系、代价和结果时，最好的页面类型不是“案例页”，而是“证据墙”：读者要看到线索如何互相指认。

Variant: forensic board
Evidence A抽象观点

“只要意志足够强，系统就会让路。”这句话听起来完整，但它还没有接受现实审讯。

Evidence B现实阻力

规则、资源、身份、关系网同时发力，个人选择被压缩成很窄的缝。

Evidence C关键转折

事件没有证明“人不努力”，而是证明努力本身也需要结构性条件。

Evidence D代价

当代价被隐藏时，观点会显得轻盈；当代价出现时，理论必须重新称重。

Verdict判断

案例页的核心不是复述情节，而是让观点承担现实成本。

DISPLAY LOGIC / CROSS EXAMINATION

把观点叫进审讯室

Question

你解释了成功，解释失败了吗？

如果一个理论只能解释胜利者，它其实没有解释现实，只是在给结果贴标签。

EXHIBIT 01 事件、结果、代价、反例。每一项都不是装饰，而是审讯材料。
Answer

失败不是噪声，是模型边界

真正的洞见要把失败案例纳入解释，否则它只是漂亮叙述，不是判断工具。

Takeaway

展示逻辑决定页面形态：这里不是“专家冲突页”，而是“观点受审页”。

DISPLAY LOGIC / DIAGNOSIS

把案例当 X 光片

有些内容不是要“讲清楚”，而是要“照出来”：表层事件背后藏着哪两个病灶？哪条因果链被普通叙述遮住了？

Variant: diagnostic scan

DISPLAY LOGIC / COST EXPLOSION

代价
爆破

如果案例没有代价，它只是故事。如果代价被视觉化，读者会立刻明白：这不是观点分歧，这是现实在收费。

认知成本

旧框架失效，读者必须换一套解释坐标。

行动成本

新的判断会改变选择，不再允许舒适误读。

关系成本

有些真相会破坏原来的协作叙事。

时间成本

系统性问题不能靠一句金句即时修复。

页面类型保留，但它不是入口。入口是内容信号与展示逻辑，页面类型只是落地形态。

情绪温度

04

05

HTML 落地

固定翻页器和无滚动规则，开放视觉表达。

结论：`case_shock` 不是模板名，它是一组可能的展示逻辑。生成器应该选择逻辑，再选择形态。
