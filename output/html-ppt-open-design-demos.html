Fixed Player / Open Design

固定底盘，开放表达

HTML-PPT 的铁律应该保护阅读体验，而不是把每本书压进同一个模板。翻页、无滚动、容量控制固定；风格、构图、节奏和内容组织放开。

Boundary
固定键盘、滚轮、点击、导航点、进度条、单页 100vh、无内部滚动。
开放出版物、瑞士网格、黑场审判、杂志专题、研究报告等视觉方向。
验收美观、完整、可读、有逻辑，页面服务内容而不是内容填模板。
Demo 01
Case Shock

案例不是例子，是观点撞墙的声音

这一页不再用固定卡片阵列，而是做成档案袋。适合展示事件、结果、代价，让抽象讨论被现实切开。

Layout Variant A
Event

一个决定被现实追问

把书中的关键事件放在视觉中心，而不是压缩成“案例说明”。读者先看到事实，再看观点。

Outcome

结果改变解释权

结果区只保留最硬的转折：谁付出代价，谁获得收益，谁的假设破产。

Cost

代价必须可见

如果没有代价，冲突就会变成观点表演。案例页必须让“代价”成为页面结构。

Takeaway

现实负责验算理论

这一类页面的最终洞见不是金句，而是把理论边界清楚地画出来。

认知位移
不是四栏模板

同样是 cognitive upgrade，可以用瑞士网格做成“旧坐标到新坐标”的位移图。内容仍完整，但视觉语言完全不同。

Old Frame

旧思维

把问题理解为个人选择、道德品质或单点能力，于是解决方案总是落到劝说、修补和局部优化。

→
New Frame

新思维

把问题理解为系统约束、资源结构和反馈机制，于是行动从“改变人”转向“改变生成结果的条件”。

Attack

你的解释太干净了

专家 A 的攻击不是为了制造热闹，而是逼问一个理论没有覆盖的脏问题：当人性、利益和制度同时在场，模型还能不能成立？

冲突页必须暴露理论边界。
冲突不是装饰 它负责把一个看似完整的观点，推到必须承担代价的位置。
Defense

脏问题才是入口

专家 B 的回应不是退回安全区，而是承认复杂性，并给出更窄、更真实的适用边界。

回应页必须留下新的判断。
Magazine Spread

洞见页可以像专题排版

不是每个 insight 都要变成同款卡片。重要洞见可以占据大版面，次级洞见成为旁栏，形成阅读层级。

Layout Variant B
01 / MAIN INSIGHT

真正的深度，是让读者换一套判断坐标

如果一页只是把原文说得更漂亮，它没有升级。洞见页必须让读者带走一个下次还能使用的判断框架。

02

旧共识必须出场

没有旧共识，所谓新洞见就没有位移感。

03

案例负责加重

案例不是装饰材料，而是让观点承担现实重量。

新模式看的是整套节奏

模板感来自连续页面的同质化。新的生成器应该先排节奏，再渲染页面：强弱、明暗、解释、案例、冲突、收束都要有位置。
